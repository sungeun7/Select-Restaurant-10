# 맛집 다이어리

직접 다녀온 식당 후기를 남기고, **나만의 최고 맛집 Top 10**을 한눈에 보는 모바일 웹 앱입니다.  
**갤럭시·아이폰**에서 홈 화면에 추가하면 앱처럼 실행됩니다.

## 기능

- **후기 쓰기**: 식당 이름, 위치, 평점(1~5), 사진, 한줄 코멘트, 상세 후기, 방문일
- **포인트**: 후기만 50P, 사진 포함 100P 적립
- **내 Top 10**: 평점 순 상위 10개 맛집
- **전체 후기**: 저장된 후기 목록 (최신순) · 수정/삭제
- **PWA**: 홈 화면 추가 시 앱처럼 전체 화면 실행, 오프라인 캐시

## 갤럭시(Android)에서 앱으로 사용하기

1. **Chrome**으로 이 웹페이지를 엽니다. (반드시 **https** 주소 또는 로컬 서버로 접속)
2. 메뉴(⋮) → **"앱 설치"** 또는 **"홈 화면에 추가"** 선택
3. 설치 후 홈 화면에 생긴 **맛집 다이어리** 아이콘을 탭하면 앱처럼 실행됩니다.

## 아이폰(iOS)에서 앱으로 사용하기

1. **Safari**로 이 웹페이지를 엽니다.
2. 하단 **공유** 버튼(□↑) 탭
3. **"홈 화면에 추가"** 선택 → 이름 확인 후 **추가**
4. 홈 화면에 생긴 **맛집 다이어리** 아이콘을 탭하면 브라우저 UI 없이 앱처럼 실행됩니다.

## 실행 방법 (개발/테스트)

앱 설치·오프라인 기능을 쓰려면 **반드시 웹 서버**로 띄워야 합니다. (파일 직접 열기 `file://`에서는 PWA 동작 안 함)

```bash
# 프로젝트 폴더에서
npx serve .
# 또는
python -m http.server 8080
```

그 다음 브라우저에서 `http://localhost:8080` (또는 표시된 주소)로 접속한 뒤, 위 방법으로 홈 화면에 추가하면 됩니다.  
실제 갤럭시/아이폰에서 쓰려면 **HTTPS**로 서비스되는 주소가 필요합니다 (예: GitHub Pages, Netlify, 본인 서버).

## 파일 구성

- `index.html` - 메인 페이지
- `styles.css` - 스타일
- `app.js` - 후기·포인트·UI 로직, Service Worker 등록
- `manifest.json` - PWA 앱 이름, 아이콘, 전체 화면 설정
- `sw.js` - Service Worker (캐시·오프라인)
- `icons/icon.svg` - 앱 아이콘

## 기술

- HTML5, CSS3, JavaScript (Vanilla)
- localStorage (후기·포인트 저장)
- PWA (manifest + Service Worker), 모바일 퍼스트 UI

데이터는 서버로 전송되지 않으며, 사용 중인 기기의 브라우저에만 저장됩니다.
